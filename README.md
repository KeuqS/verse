# Verse

Verse is a browser-based writing companion for poets. It provides a writing canvas, literary-influence selection, example-based writing suggestions, a local poem collection, and export/sharing controls.

## Run locally

Prerequisites: Node.js 22 or newer and npm.

```bash
npm ci
npm run dev
```

Verify a production build with `npm run build` and review static analysis with `npm run lint`. The production output is `dist/`.

## Hosting

This repository is configured to build and deploy the static application with GitHub Actions and GitHub Pages, independently of Lovable and Vercel.

1. In **Settings → Pages**, choose **GitHub Actions** as the build/deployment source.
2. The workflow at `.github/workflows/pages.yml` publishes `dist/` from `main`.
3. GitHub Pages project hosting uses `https://fraware.github.io/verse/`.
4. Direct URLs such as `/verse/write` and `/verse/collection` use the published SPA fallback.

## Data and feature boundaries

Poems are stored **only in the current browser's localStorage** under `verse_poems`. There is no account, server-side database, cross-device synchronization, or automatic backup. Clearing site data or switching browser/device can erase access to saved poems. Export or copy important writing independently. Poem visibility is private to the browser unless explicitly shared using an external destination.

The writing suggestions are **local, predefined examples** associated with literary influences. They are not generated by a model and their numerical scores do not establish objective literary quality. No API keys or hosted inference are required.
